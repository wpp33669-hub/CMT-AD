# CMT-AD

Official implementation of **CMT-AD: Confidence-Guided Cross-Modal Knowledge Transfer for Multimodal Anomaly Detection in Microservice Systems**.

This work has been submitted to **IEEE Transactions on Software Engineering (TSE)**.

## Overview

CMT-AD is a multimodal anomaly detection framework for microservice systems. It jointly models KPI and log data and introduces a confidence-guided cross-modal knowledge transfer mechanism to adaptively exploit complementary information from different monitoring modalities.

## Environment

The project can be run using **PyCharm** or directly from the command line.

Please install the required dependencies before running the code.
